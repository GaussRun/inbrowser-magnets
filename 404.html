    This page is a static reader. The link carries the sha256 of a Markdown post. The page asks many independent hosts for that hash at once, keeps the first copy whose hash matches and renders it, so a post stays readable when the author's site is down. The page itself is one file, copied to many hosts the same way.

    Link shape

    https:///#v1.<sha256 hex> is the minimum. Optional parts follow, each after a dot: the author's Nostr pubkey (64 hex or npub), then hints separated by ~ saying where copies live. * in a hint stands for the hash. Everything after # stays in the browser and never reaches any server.

    o:owner host, /h/*.md on ito:example.org
    g:GitHub repo via raw, jsDelivr, Staticallyg:user/repo@main
    t:URL template with *t:cdn.example.org/p/*.md
    s:extra Blossom servers:blossom.example.org
    n:extra Nostr relayn:relay.example.org
    a:Arweave transaction ida:JpCbBtEL62oENawwQnAT5r-bw7jETYeP55s2KLqGacA
    b:Bluesky PDS blob by DIDb:did:plc:abc123/bafkreiexample
