# Hello magnets

This is the smallest test post for the inbrowser-magnets reader. The link that
brought you here carries the sha256 of this exact file. The reader asked several
static hosts for a copy at the same time, kept the first answer whose hash
matched, and threw the rest away.

Nothing on this page depends on the host that served it. If the home host is
down, blocked or seized, the same bytes come from a GitHub mirror, a Blossom
server, an IPFS gateway, Arweave or a Nostr relay.

## Why a magnet

A magnet link names content, not a location. This post is one of three test
posts: this one is about one kilobyte, the medium one is about twenty, and the
large one is about one hundred. They exist so the reader can be tested against
real hosts, with real latency, from a cold cache.

- hash: in the link fragment
- copies: everywhere the publisher could put them for free
- trust: only the hash

That is the whole idea.
