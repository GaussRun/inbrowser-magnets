# Magnet Notes

Notes from building inbrowser-magnets, a static reader that fetches a Markdown post by its sha256 from many free hosts at once and renders the first copy whose hash matches. This blog is itself a set of such posts: every page you open here, including this one, arrives through the same race, from whichever host answers first with the right bytes. The footer of each page names the host that won.

Here is what we measured.
